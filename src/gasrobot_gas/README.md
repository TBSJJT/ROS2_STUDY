# gasrobot_gas

GasRobot 的气体传感器驱动、标定、滤波和浓度处理包。

当前尚未确定最终气体传感器型号和通信协议，因此本包保持为可编译骨架。
跨软件包接口已经在 `gasrobot_interfaces` 中定义，后续驱动必须保证消息时间戳
对应真实采样时刻，为 TF2 历史位姿补偿提供可靠时间基准。

## 后续代码约定

- 设备通信和原始采样节点放在本包。
- 传感器动态响应实验、滤波、阈值和风险等级判定放在本包。
- 稳定的项目消息、服务和动作定义放在 `gasrobot_interfaces`。
- 当前位姿关联、历史 TF 查询和风险位置补偿放在 `gasrobot_gas_mapping`。
- 启动文件由功能包提供，整机组合入口放在 `gasrobot_bringup`。
